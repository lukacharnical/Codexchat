# CodexChat

Application mobile de messagerie et de développement.

## Fonctions prévues

- 💬 Messagerie en temps réel
- 💻 Éditeur de code
- 📚 Bibliothèque de projets
- 🤖 Assistant IA
- 🔄 Synchronisation GitHub
- 👥 Collaboration sur les fichiers

## Langages supportés

- HTML
- CSS
- JavaScript
- Python
- Java
- C++
- Ruby
- Dart
- Kotlin
